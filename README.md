# LeetCode Complexity Analyzer (Gemini) – side panel

React + TypeScript + Tailwind v4 + shadcn-style components, LeetCode dark theme.

    npm install
    npm run build        # outputs dist/

Chrome: chrome://extensions > Developer mode > Load unpacked > select `dist/`.
Click the toolbar icon once: the side panel opens and stays open across tabs.
Open the gear icon, paste your Gemini API key (https://aistudio.google.com/apikey).
On a leetcode.com/problems/... page, press Analyze.

Requires Chrome 114+ (Side Panel API).
